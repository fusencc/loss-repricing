# 官方调价日志接入与分口径价格存档

用户2026-11-17要求先把已实测的官方日志接口接入程序，记录上传价、税前价、
实际含税价和营销价，供后续扩展。范围为后端查询、现有真实人工执行核验链路和存档；
不发起新的调价、不启用自动任务、不修改价格公式或72小时保护口径。

复用已确认的两条官方POST查询：按SKU/type/完成时间统计数量，以及查询最近成功价。
它们不提供完整的执行ID、币种和生效时间证据，不能替代现有任务详情及平台当前价。
独立适配器记录查询范围、请求/响应、状态、查询时间；失败为未知，非默认零。
最近成功价先保持独立金额，和同目标操作日志priceNew一致时标记本次税前金额匹配。

统一price_record包含四个独立价格对象（十进制字符串、币种及其来源、字段路径、
采集时间）、平台税前回读、任务ID/状态/操作人/创建及完成时间、官方查询及比较结果。
上传价来自原Execution.request，不被平台换算后的价格覆盖。
当前来源的查询时点不冒充平台update_time或调价完成时点。

ManualLiveAdapter的成功核验生成记录，LookupResult传回服务层，随Execution.evidence
持久化；原判定字段actual_price仍指营销实际价。官方查询失败单独留证，不推翻已有
独立平台成功和实际价证据。官方记录不参与自有72小时历史筛选。

为已核验执行提供只读补档CLI：只调用lookup，核对mode/执行ID/目标后追加price_record
与审计记录，保留原confirmed_at/effective_at、状态和目标锁。原档案不覆盖，新增版本
目录包含JSON、中文摘要及SHA256清单。无需新增数据库表或兼容旧接口。

验证：mock HTTP精确请求、错误/零/缺失/金额精度、四价来源和身份；服务持久化及
补档不上传/不改变保护时间。真实验收只读复查已完成商品，存档到runtime和原桌面项目。
