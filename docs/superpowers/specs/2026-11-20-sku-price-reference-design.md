# 同 SKU Top3 营销参考价

用户在本会话已确认：同站点、同本地子 SKU、同仓配，排除本链接，以近七天子 SKU 销量排序取三条其他在售链接。每条参考营销价统一为「含 VAT 税后价 ×（100－折扣百分数）÷100」，三条取算术平均，不用中位数或销量加权。明确没有折扣按 0 计算；缺失折扣且不能证明无折扣时不猜 0。

用户确认参考价作为上限，并明确参考价优先于1%在线利润要求：先计算补亏及1%所需价格，再取不超参考的最高可上传档位，超出时按该档位调整。即使利润不足1%、为负，或当前价已达到／超过上限，也继续处理，允许降价或同价，不因此标为不调价或待处理。没有参考时仍按原1%规则。费用系数使1%没有有限解时，有参考就直接按参考档位，最低通过价及校正额留空，不伪造数值。实际预计利润和利润率仍如实保存。

人工明确指定价或进档后价超上限时拒绝原方案，不能静默改价后沿用旧授权；在上限以内不因利润不足1%而拒绝。回读根据本次请求保存的`sku-reference-priority-v2`规则处理：有参考不再以1%否决；仍核对目标误差、身份、任务及保存上限，不使用金额误差容限放过超限。未采用该规则的历史请求不重新解释。

缺少三条、有销量的其他链接不足、无新增销量、字段缺失、查询失败或查询超出受控范围，都只省略上限，继续原定价规则，不新增待处理、告警或中断其他流程。零销量不参与；不自动换到30天或使用一两条冒充Top3。旧的仅参考历史不回写或重新解释。

采用当前已核实的销售系统列表和子规格只读接口；现有开放接口不足以跨店发现销量和价格。只查询需要参考的本地子 SKU/站点（允许混挂不同父主 SKU），复用本次平台记录与已读规格，按组缓存，限定分页及查询数量。参考最多用30秒，核心快照剩余不足60秒时不查，避免参考查慢使现价依据过期。参考价所需的销量、税后价、折扣和仓配均来自同一次子规格响应，不新增活动/利润/费用查询。

三条样本的原价、折扣、计算营销价、销量、店铺及产品/规格 ID、观察时间与查询证据一起保存。金额采用 Decimal 精确比值，前端只显示后端结果。有效参考优先时，记录页第三环节显示「参考价优先」，不声称1%利润已达标。非必需参考与核心定价来源分离，不进入来源完整性和提交授权检查；已有历史不回写。重复观察的核心现态一致时采用同币种有效参考中的较低上限，并保存一个规范在线模型行供回读，原观察保留在批次快照。
