# 机器人通知运行接入

目标：用户要求接通并持续运行，按销售员 userId 机器人私聊。

沿用持久通知队列、防重、未知不重发、当前归属检查。替换旧工作通知接口，不保留双轨发送。机器人摘要不依赖尚未部署的公网网页。独立通知进程仅处理真实档案通知，不运行定价任务。Windows 任务计划常驻及恢复；电脑关机期间不能发送。

- [x] 用测试核验机器人固定接口、目标 userId、无网页发送、目标已读状态及未知不重发。
- [x] 从当前应用读取独立凭据，配置真实通知。
- [x] 部署独立通知进程、健康状态与 Windows 任务计划。
- [x] 核对已确认归属、实际发送和回执，验证进程恢复。

验收：通知与免登录测试41项通过；补充回执降频等4项通过；真实机器人测试已读；吴娟业务4条（3已读、1已送达）；通知子进程被终止后守护15秒拉起新PID且没有重复发送。Windows任务计划拒绝访问，实际采用当前用户登录自启动守护。
