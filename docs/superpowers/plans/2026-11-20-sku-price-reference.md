# 同 SKU 营销参考价实施计划

> **For agentic workers:** Use superpowers:executing-plans，当前会话直接实施。用户已确认公式并授权接入。

**Goal:** 计算同 SKU 七天销量 Top3 营销均价，有值时作为上限，缺失仍按原规则继续。

**Architecture:** 可选只读采集器提供三条价格来源；领域纯计算生成均价；常规与人工入口绑定快照，记录 API 和现有详情显示同一保存值。

**Tech Stack:** Python 3.12 / Decimal / httpx / pytest / Vue 3 / TypeScript。

**Spec:** `docs/superpowers/specs/2026-11-20-sku-price-reference-design.md`

## Global Constraints

使用 WSL 现有功能分支；不部署、不真实上传。按用户最新确认，有参考时参考上限优先，利润不足或需降价不阻断；没有参考时仍使用原1%利润规则。参考缺失不进待处理，不新增兼容层或旧来源回退。

## Review Focus

无折扣、零/缺销量、不足三条、跨站/仓配混入、接口失败或分页不完整；分别验证参考省略且原定价及状态一致。按已确认字段处理，不把父商品销量当作子 SKU 销量。
