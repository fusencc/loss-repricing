# 亏损补亏程序 Implementation Plan

Goal: 建立可运行的服务器程序，完成合格候选自动取数、计算、提交与核验。
Spec: ../specs/2026-11-05-loss-repricing-design.md
Architecture: Decimal纯规则 + 数据适配 + MySQL持久任务 + 管理API/Vue网页。模拟与真实环境隔离。

## Global Constraints
各子SKU分别取小；21件保护；72小时；前7完整北京时间自然日；直接补亏后利润复核；真实未知结果不重传；生产仅保留关键检查；不接钉钉；核心计算与数据来源详细中文注释。

## Tasks
- [x] 1. 核心领域类型、规则引擎、中文注释与规则测试。输出标准Snapshot和Decision。
- [x] 2. 按执行中用户调整，保留模拟/文件/HTTP接入边界，核对旧接口和公式出处；上传模板与响应测试完成，真实字段未冒充确认。
- [x] 3. 数据库迁移、稳定目标防重、后台调度/恢复、API与认证；SQLite集成及迁移测试完成。
- [x] 4. Vue管理页，包括概览、批次、计算详情、单目标异常重评、保护和运行配置；构建与实际浏览器检查完成。
- [x] 5. 独立Compose预留、Windows本地启动/停止、运维和数据来源文档；本地完整测试与审阅完成。

真实数据抓取、MySQL容器运行验证、服务器部署及真实试点按用户最新指示留待数据源准备后接入。本轮没有执行这些生产动作，不能以已完成的本地演示替代生产验收。

## Review Focus
跨SKU错误取小；未知提交跨批重传；时间窗口跨日；费用口径/折扣含义混用；管理开关与凭据泄漏。分别由领域测试、数据库恢复测试、调度测试、适配测试和API权限测试覆盖。
