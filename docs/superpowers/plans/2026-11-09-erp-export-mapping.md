# ERP 与销售原始导出接入 Implementation Plan

目标是用已保存批次的订单号、店铺与父产品范围，将 ERP 商品明细导出接到销售在线变体导出。保持现有算价引擎和只读报告的业务边界。输入约束以当日样本与已确认连续接入设计为依据。

- [x] 测试原始 ERP 与销售工作簿自动映射，保持跨来源、跨订单及同订单多行的证据。按店铺、父产品和本地 SKU 查找，明确拒绝多个不同的在线目标。
- [x] 在 `app.adapters.erp_export_mapping` 解析白名单字段和来源引用。使用文件摘要与物理行号回查，稳定明细 ID 由独立证据提供。
- [x] 通过 `preview_pricing` 接续映射结果。带审批过的补充证据时，核对每条的来源引用、商品键与数量，再交现有算价引擎。缺口留痕且依旧可查看其他映射。
- [x] 在现有管理员预览面板接入两份 XLSX，复用报告查询、分页和下载。用真实保存批次与两份原件核对 5 单、10 行、9 个候选变体，并用合成证据验证最小亏损规则与全链路。
