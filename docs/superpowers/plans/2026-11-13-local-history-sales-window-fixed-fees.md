# 历史、费用与库存来源实施说明

当前业务口径以[核心计算规范](../../calculation-and-sources.md)与[已确认设计](../specs/2026-11-05-loss-repricing-design.md)为准。

## 来源与职责

- 官方近72小时调价日志用于近期调价保护；本地真实执行档案用于人工保护和未完成提交锁。未知提交只核验，不自动重传。
- 销售系统每日费用与物流快照提供完整在线利润模型，库存决定采用海外仓或直发公式。
- adapters 转换来源并保存证据，services 编排有效来源，domain 统一使用 Decimal 计算补亏、折扣与利润。
- 同 SKU Top3 营销参考价使用销售系统子规格销量及价格，按独立合同采集与保存。

## 验证要求

- 来源异常按目标隔离，数量、币种、费用模型和历史证据保持真实，不填零或回退旧文件。
- 覆盖库存分流、VAT、成本汇率、折扣逆算、上传档位、利润和参考价上限。
- 先构建前端，再运行后端测试。模拟测试通过不代表真实上传或价格生效验收。
- 真实提交开关与试点授权保持独立，文档或代码清理不改变执行授权。
