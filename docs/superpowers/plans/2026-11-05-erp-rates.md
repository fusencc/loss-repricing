# 公司汇率只读接入计划（2026-11-05）

按用户要求先实现接口查询。沿用现有独立 ERP 登录配置，不修改业务定价公式或启用真实提交。

1. 新增 `adapters/erp_rates.py`：登录取得 token，GET 查询全部汇率；Decimal 解析；返回原值、50位精度的倒数参考值、采集时间及逐币种异常。
2. 新增管理员 API `/api/sources/erp/rates` 和设置页查询面板；仅明确点击时查询，即使 demo 模式也明确标识为公司真实只读来源，不写 demo 历史。
3. 以 HTTP Mock 验证认证、业务错误、坏币种隔离、日期缺失和日志脱敏；接口方向按实测推断标记未确认，`effective_date=null`、`pricing_ready=false`。不把响应时间充作生效日期，不注入 Snapshot。
4. 同步来源规范，先前端构建再后端测试；通过新增客户端做真实只读查询，输出摘要，不落盘原始响应或凭据。

查询结果在内存中返回，未引入数据库迁移。现有 HttpAdapter 的通用已确认汇率合同保持原样；待真实方向与生效规则确认后再单独接入自动计算。
