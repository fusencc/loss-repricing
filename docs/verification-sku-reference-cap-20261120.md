## 当前规则

- 同币种Top3的精确营销均价作为价格上限，继续按税后价×（100－折扣）÷100计算。先计算补亏及1%所需价格，再取不超参考的最高可上传档位；只压减超出部分。
- 参考上限优先。即使利润不足1%、为负，或现价已经等于／超过参考，也继续按参考档位处理，允许降价或同价；没有参考时仍按原1%规则，不因缺参考新增待处理。
- 1%没有有限通过价时直接按参考档位，最低通过价及校正额为null；预计利润、实际回读利润及是否达到1%如实记录。记录页第三环节显示「参考价优先」。
- 人工明确价在上限以内不因利润不足1%拒绝；超过上限仍需修正原方案，不能静默改写明确价格授权。
- 回读按本次保存请求判定参考优先；不足1%可核验，不再暂停本站点。实际价超过保存上限即使在原金额容限内仍不能核验成功，沿用超差规则。历史请求不重新解释。
- 核心现态一致的重复观察采用同币种较低上限，规范为一个在线模型行供回读；原始观察留在批次快照。小于上传最小档位的正参考只影响该条，不因利润率除零中断独立商品。
