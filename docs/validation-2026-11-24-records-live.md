# 2026-11-24 提价日志实时更新验证

## 当前行为

用户要求提价上传、实际有效价核验结果逐条保存后及时更新前端。检查确认 `PricingService._submit` 已逐条提交上传回执，`reconcile` 已逐条提交核验结果；本次保留这些事务及真实执行语义，不改变公式、上传合同或核验标准。

新增只读 `/api/records/stream`，通过服务器发送事件（SSE）发送当前部门的完整已保存日志视图。首帧立即读取当前数据，之后每秒通过独立短数据库会话复用 `department_records`；变化才推送业务数据，未变化发送心跳。无进程内事件依赖，独立 worker 落库也可见；每次查询结束释放会话，不把未提交数据发送给页面。主应用与部署时的独立只读日志服务共用流响应。独立服务延用正式档案和展示归属，公开代理只需加同范围的 GET 入口。响应设置禁止缓存和 `X-Accel-Buffering: no`，避免现有 Nginx 缓冲。

首页移除原 60 秒轮询，接收完整视图后同步更新部门统计与已打开的销售员日志；切部门关闭旧连接并使旧回调失效。隐藏及卸载时关闭连接，重新可见时重新读取；断线由浏览器 EventSource 自动重连，页面提示当前记录可能过期。原 `/records` 查询仍供现有独立读取方使用，不作为实时连接的回退分支。

约一秒加数据库查询和网络耗时为显示延迟，不代表上传受理后价格立即生效。已计算、待核验、已核验及未知提交的原有区别不变，未知请求不自动重传。
