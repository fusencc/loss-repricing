# 亏损补亏工作台

项目目录：`D:\projects\loss-repricing`。本轮交付的是可在本机运行的演示程序：规则计算、管理网页、持久任务、模拟提交与逐条模拟核验已经串起来。真实ERP/销售数据抓取由后续整理后接入，当前没有生产部署，也没有执行真实调价。

## 打开程序

在PowerShell执行：

```powershell
Set-Location -LiteralPath 'D:\projects\loss-repricing'
.\deploy\start-local.ps1
```

打开 [本地工作台](http://127.0.0.1:18765)。账号为`admin`；密码保存在项目根目录`.env`的`LR_ADMIN_PASSWORD`中，请在本机查看，不复制到文档、截图或聊天记录。启动脚本首次运行时生成独立密码及会话密钥，不使用公司业务账号。

登录后点击“运行演示批次”，再从“运行批次”查看商品详情、补亏计算和核验证据。演示数据与回执都在本机生成，**该按钮不会访问公司系统或真实调价**。“已核验”在demo模式下表示模拟价格已核验，页面和记录会保留模式说明。

关闭后台服务：

```powershell
.\deploy\stop-local.ps1
```

两个脚本只管理本项目记录且身份匹配的Python进程树，包含Windows虚拟环境启动器创建的解释器子进程。启动、停止及18765端口释放已在本机验证。关闭网页不会停止后台worker。启动时加`-NoBrowser`可只启动服务；强制停止后立即重启，任务可能等待旧worker最长120秒的租约到期，再由新worker接管，不应清锁催跑。

## 本轮包含的能力

- 管理员登录、运行概览、批次与商品计算详情、待处理记录、保护名单、试点与暂停配置。
- 按具体在线子SKU取最小有效单件亏损；数量、币种、仓配、费用口径、销量保护、历史和折扣校验。
- 当前实际价直接补亏、含VAT上传价反推、站点档位舍入、正常一次毛利复核；不通过转待处理，不自动追加涨价。
- 任务、来源快照、执行意图、实际上传目标锁和模拟回执持久保存；源SKU改名不绕过防重及72小时保护，未知结果仅查询核验。
- 单条重新评估只处理选中的实际目标；跨北京时间午夜停止昨日未提交项，排队用新日数据重算。
- 演示模式、标准化JSON文件对账模式，以及合同驱动的真实适配器边界；保留Excel上传模板生成能力。

用户可见结果统一为“本轮不调、待处理、待核验、已核验”。上传受理、行处理和有效价核验分别留证，受理不等于已生效。

全局概览与异常列表按实际上传目标展示最新评估，并额外保留该目标尚未结束的旧执行，避免新记录遮住未知结果。批次详情仍保存原判定与证据，不删除历史。

## 当前模式与后续范围

| 模式 | 当前用途 | 是否真实提交 |
|---|---|---|
| `demo` | 合成数据、模拟回执，演示完整流程 | 否 |
| `file` | 读取规范化JSON快照，核对业务规则 | 否，适配器拒绝上传 |
| `live` | 预留按已确认合同读数、上传和查价的边界 | 本轮关闭；未完成真实接入和端到端验收 |

真实接入还需确认四份ERP候选字段、唯一在线变体映射、当日汇率、公司正常一次毛利模型、站点税后价格列/档位、上传逐行结果以及当前有效价来源。`deploy/live-contract.example.json`明确为未确认模板，不能把示例或合成数据当作公司真实合同。

后续目标是在已确认的试点范围内按规则自动执行，异常留待处理；本轮不把真实生产自动化列为完成。项目不连接钉钉，不修改历史订单，不解除禁止发货或自动退出活动。

## 技术与目录

后端为Python/FastAPI、SQLAlchemy/Alembic及持久worker，前端为Vue 3、TypeScript、Vite、Element Plus。本地演示使用SQLite；生产规划采用独立MySQL。计算使用Decimal。

```text
backend/app/domain/       数据类型与纯计算规则
backend/app/adapters/     demo、JSON文件及真实合同适配边界
backend/app/services/     批次执行、防重、持久任务
backend/app/worker.py     定时、任务领取和恢复核验
frontend/                管理网页
deploy/                  本地启动、停止、界面检查与部署预留
tests/                   规则、接口、执行与恢复测试
runtime/                 本机数据库、模拟回执、日志与截图（不入Git）
docs/                    算价来源、数据合同证据与运行说明
```

## 验证与文档

在项目根目录运行后端测试：

```powershell
.\.venv\Scripts\python.exe -m pytest
```

在`frontend`目录执行`npm.cmd run build`检查类型并构建前端。服务启动后，在项目根目录执行`.\.venv\Scripts\python.exe deploy\smoke-ui.py`，可验证实际登录、演示批次、详情、配置及窄屏界面。该脚本仅允许demo模式，不打印密码。
